About StockVault

Our Mission

StockVault is a modern inventory management system designed to help businesses of all sizes track, organize, and optimize their stock levels. Built as part of the INF 213D Final Project, this application demonstrates the fundamentals of web development including HTML structure, CSS styling, form handling, and responsive design.

Our platform provides intuitive tools for adding items, viewing inventory data in structured tables, and navigating seamlessly between different sections of the application.

Key Features

Feature Description
Dashboard Overview of inventory status
Search Find items by name, ID, or category
Add Items Form with validation for new entries
Status Tracking In Stock, Low Stock, Out of Stock

This website was created as a final project for INF 213D. It features at least 4 pages, external CSS styling, tables with both visible and invisible borders, forms with radio buttons, checkboxes, and text fields, as well as rollover images, hyperlinked images, and properly styled content.
